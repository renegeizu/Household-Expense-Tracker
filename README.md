# Commonplace

A local-first household finance application. The [`doc/README.md`](doc/README.md) is the documentation index.

- [Architecture](doc/arquitectura.md)
- [Installation and operations](doc/guia-instalacion.md)

Quick start from this directory:

```sh
make help
make up
```

The development app runs at <http://localhost:5173>. All application commands run inside Docker; host-side Node.js/npm are not required.
